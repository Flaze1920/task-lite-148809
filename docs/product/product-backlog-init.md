| # | Capacidad                             | Clasificación     | Valor                                                                          |
| - | ------------------------------------- | ----------------- | ------------------------------------------------------------------------------ |
| 1 | **Registrar tareas**                  | Esencial para MVP | Permite incorporar nuevas tareas al sistema para darles seguimiento.           |
| 2 | **Visualizar tareas**                 | Esencial para MVP | Permite consultar de forma clara las tareas existentes.                        |
| 3 | **Consultar el estado de las tareas** | Esencial para MVP | Permite identificar rápidamente qué tareas están pendientes o en otro estado.  |
| 4 | **Actualizar el estado de una tarea** | Esencial para MVP | Permite mantener actualizada la situación de cada tarea.                       |
| 5 | **Editar información de una tarea**   | Posterior         | Permite corregir o actualizar información de una tarea después de registrarla. |
| 6 | **Eliminar tareas**                   | Posterior         | Permite retirar tareas que ya no necesitan formar parte del seguimiento.       |
| 7 | **Filtrar tareas**                    | Posterior         | Permite localizar más fácilmente tareas según determinados criterios.          |
| 8 | **Buscar tareas**                     | Posterior         | Permite encontrar rápidamente una tarea específica cuando aumente su cantidad. |
